# DEMO AURA BEAUTY

A fashion-editorial beauty studio concept built with React, Vite, Tailwind CSS and Framer Motion. The images are bundled locally in `public/images`, so the experience does not depend on external image CDNs.

## Run locally

```bash
npm install
npm run dev
```

Create a production build with `npm run build`.

## Included interactions

- Floating, responsive navigation with an animated mobile menu
- Independent hero-letter reveals and a slow rotating aura seal
- Scroll reveals, parallax details, drawn-line reveal and a pinned horizontal lookbook
- Hover/tap-responsive service list and artist portraits
- Keyboard- and touch-friendly before/after range control
- Count-up statistics, manually navigable testimonial slider and two-step aura quiz
- Appointment form with animated local confirmation, plus WhatsApp links
- Reduced-motion support and layouts tailored for mobile and desktop

This is a client-demo concept: the appointment confirmation is front-end only, and the WhatsApp number, Instagram handle, prices and studio details are sample content intended to be replaced for a real salon.
